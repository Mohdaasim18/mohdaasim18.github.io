01 HARDWARE / FIRMWARE

PicoLink — RP2040

An RP2040-based VGA graphics system developed using the Raspberry Pi Pico SDK. The project explores real-time display generation, programmable I/O, memory management and custom hardware development.

VGA Signal Generation

Implemented VGA output using RP2040 PIO state machines. Worked with horizontal and vertical synchronization, RGB signal generation and VGA pin configuration.

PIO & DMA

Used Programmable I/O for timing-sensitive display operations and DMA for transferring display data with reduced CPU involvement.

Framebuffer & Memory

Worked on framebuffer-based graphics, pixel representation and colour encoding. Explored memory constraints while handling display resolution and colour depth.

Custom PCB Development

Worked on custom RP2040 hardware involving VGA connectivity, USB interfaces, component integration, soldering and board-level debugging.
